## 火星（♂）—— 行动力、脾气、欲望、竞争

> 火星落座 = 你的行动方式和脾气爆发点。火星是"战士"，落座决定了你怎么争取、怎么发火、怎么驱动自己。

| 星座 | 尊贵 | 落座解读 |
|------|------|---------|
| 白羊 | 守护 | 行动力直接果敢，勇气十足；脾气来得快去得快，竞争欲强，敢闯敢拼争第一 |
| 金牛 | 弱 | 行动力缓慢但持久固执；脾气闷燃型，一旦爆发极可怕，欲望偏物质和感官 |
| 双子 | — | 行动力靠思维驱动，精力分散多变；脾气靠嘴发泄，喜欢口舌争辩，行动不够专注 |
| 巨蟹 | 陷 | 行动力受情绪牵制，怒火内化不外露；被动攻击倾向，欲望偏情感安全，保护性强 |
| 狮子 | — | 行动力自信张扬，做事有气势；脾气傲慢型，需要面子，竞争欲强且爱赢 |
| 处女 | — | 行动力精密有条理，做事注重细节效率；脾气压抑型，容易因不完美而焦躁 |

| 摩羯 | 旺 | 行动力有纪律有目标，耐力持久；脾气克制型，竞争方向明确，执行力卓越 |
