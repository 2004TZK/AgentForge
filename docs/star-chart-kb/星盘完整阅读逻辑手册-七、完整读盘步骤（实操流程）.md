## 七、完整读盘步骤（实操流程）

按这个顺序读，不会乱、不会漏：

### 第1步：定格局 —— 看四轴和整体分布

先看星盘的"骨架"：
1. **上升星座（ASC）**：外在性格、第一印象、外貌气质
2. **天顶星座（MC）**：事业方向、社会形象
3. **下降星座（DES）**：吸引的伴侣类型
4. **天底星座（IC）**：原生家庭模式、内心安全感来源

> 四轴是星盘的四个"锚点"，先定大方向再看细节。

### 第2步：看个人行星 —— 日月水金火

逐个看五颗个人行星的落座和落宫，这是你最核心的性格：

| 行星 | 重点看什么 |
|------|-----------|
| 太阳 | 你的核心自我、人生主线 |
| 月亮 | 你的情绪模式、安全感来源 |
| 水星 | 你的思维方式、沟通风格 |
| 金星 | 你的恋爱模式、审美偏好 |
| 火星 | 你的行动方式、脾气爆发点 |

> 对每颗行星都套用公式：**行星 + 星座 + 宫位 = 这颗星在哪个领域、以什么风格运作**

### 第3步：看外行星 —— 木土天海冥

外行星走得慢，**落宫比落座更重要**：
- **木星落宫**：你哪个领域容易有好运、机遇
- **土星落宫**：你哪个领域压力最大、需要苦修
- **天王星落宫**：你哪个领域容易突发变动、求新求变
- **海王星落宫**：你哪个领域容易迷糊、有灵性或逃避
- **冥王星落宫**：你哪个领域执念最深、会经历彻底蜕变

### 第4步：看相位 —— 能量之间的互动

1. 先找**个人行星之间的相位**（日月、月金、金火等）：直接影响日常性格和内心冲突
2. 再找**外行星和个人行星的相位**：人生的大课题、大机遇
3. 重点关注：
   - 太阳的相位：自我意识的整合程度
   - 月亮的相位：情绪是否顺畅
   - 金星/火星的相位：感情模式是否顺利
   - 土星的相位：哪里有压力和功课
   - 木星的相位：哪里有贵人好运

### 第5步：看宫位整体分布 —— 人生重心

观察行星集中在哪些宫位：
- 集中在**1-6宫（下半部分）**：更关注自我、内在、个人生活
- 集中在**7-12宫（上半部分）**：更关注他人、社会、外部世界
- 集中在**左半部分（12-1-2-3-4-5-6宫）**：更主观、自我驱动
- 集中在**右半部分（6-7-8-9-10-11-12宫）**：更客观、受他人影响

> 空宫（没有行星的宫位）不代表那个领域空白，看宫头星座的守护星落在哪里即可。

### 第6步：综合串联 —— 讲出一个完整的人生故事

把以上所有信息整合起来，不是罗列，而是讲出一个有逻辑的故事：
- 这个人的核心性格是什么（太阳+月亮+上升）
- 他/她在事业上是什么样的（10宫+土星+火星）
- 在感情里是什么样的（金星+火星+7宫+5宫）
- 原生家庭带来了什么（4宫+月亮+土星）
- 人生最大的课题是什么（土星+冥王星+压力相位）
- 人生最大的幸运在哪里（木星+和谐相位）
