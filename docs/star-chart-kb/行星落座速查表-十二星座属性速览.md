## 十二星座属性速览

> 解读落座时，星座的元素（火/土/风/水）和模式（开创/固定/变动）决定了能量运作的基本风格。

| 星座 | 元素 | 模式 | 关键词 |
|------|------|------|--------|
| 白羊 | 火象 | 开创 | 行动、冲劲、开创、直接 |
| 金牛 | 土象 | 固定 | 稳定、务实、感官、持久 |
| 双子 | 风象 | 变动 | 思维、沟通、灵活、多变 |
| 巨蟹 | 水象 | 开创 | 情感、保护、归属、滋养 |
| 狮子 | 火象 | 固定 | 自信、表现、热情、骄傲 |
| 处女 | 土象 | 变动 | 精密、服务、分析、完美 |
| 天秤 | 风象 | 开创 | 和谐、关系、审美、平衡 |
| 天蝎 | 水象 | 固定 | 深沉、执念、洞察、蜕变 |
| 射手 | 火象 | 变动 | 探索、信念、自由、乐观 |
| 摩羯 | 土象 | 开创 | 务实、野心、纪律、责任 |
| 水瓶 | 风象 | 固定 | 独立、创新、理想、疏离 |
| 双鱼 | 水象 | 变动 | 灵性、共情、梦幻、超越 |
