## 十、快速自查清单

拿到一张星盘，按这个清单逐项过一遍：

- [ ] 上升星座是什么？外在形象如何？
- [ ] 太阳落在什么星座、第几宫？核心自我是什么？
- [ ] 月亮落在什么星座、第几宫？情绪模式如何？
- [ ] 水星、金星、火星分别落在哪里？
- [ ] 木星落在哪里？好运和机遇在哪个领域？
- [ ] 土星落在哪里？压力和课题在哪个领域？
- [ ] 天海冥分别落在哪几宫？哪些领域有突变/迷幻/蜕变？
- [ ] 主要的和谐相位有哪些？天赋在哪里？
- [ ] 主要的压力相位有哪些？人生课题是什么？
- [ ] 行星集中在哪些宫位？人生重心在哪里？
- [ ] 四轴分别是什么星座？人生四大锚点如何？

---

> **最后一句话**：星盘是地图，不是剧本。它告诉你路的走向和地形，但怎么走、走多远，永远由你自己决定。
