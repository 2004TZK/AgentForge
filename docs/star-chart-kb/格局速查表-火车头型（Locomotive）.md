## 火车头型（Locomotive）

| 属性 | 说明 |
|------|------|
| **形态** | 行星分布在大约 240° 的范围内（占盘面的三分之二），剩余约 120° 空缺 |
| **含义** | 火车头格局代表盘主的人生有一种"轨道感"——行星分布像一列火车沿着固定方向推进。空缺的 120° 是"被拉着走"的方向，盘主会在那里感受到一种引力。火车头人的人生自带动力和方向感，不需要外界推动就能前进。 |
| **解读要点** | 1) 顺时针方向紧挨空缺区的第一颗行星是"火车头"（Leading planet），代表盘主前进的引擎；2) 空缺的 120° 区域在哪个宫位——那是盘主被"引力"拉着去面对的领域；3) 火车头人做事有节奏、有连贯性，但可能忽略空缺区的课题；4) 行进方向决定盘主是"向外推"还是"向内收"。 |
