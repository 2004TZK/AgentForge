## 月亮（☽）—— 情绪、安全感、潜意识、内心需求

> 月亮落座 = 你的情绪反应模式、内心深处获取安全感的方式。月亮是"内在的小孩"，落座决定了你最私密的情感风格。

| 星座 | 尊贵 | 落座解读 |
|------|------|---------|
| 白羊 | — | 情绪直接热烈，反应快但不持久；内心需要行动和竞争获得满足，脾气来得快去得快 |
| 金牛 | 旺 | 情绪稳定踏实，安全感来自物质和感官享受；不易被撼动，感情慢热但持久深厚 |
| 双子 | — | 情绪随思维流转，靠沟通和获取信息安抚内心；情绪多变，需要持续的精神刺激 |
| 巨蟹 | 守护 | 情感丰富细腻，极度重视家庭归属；共情力强，情绪易受环境影响，保护欲旺盛 |
| 狮子 | — | 情绪需要被看见和赞美，内心渴望被认可；温暖慷慨，情绪表达戏剧化 |
| 处女 | — | 情绪通过秩序和务实安定；内心焦虑完美，通过照顾他人的实际需求获得安全感 |
| 天秤 | — | 情绪受关系状态影响大，内心需要和谐与陪伴；审美敏感，讨厌冲突和粗鲁 |
| 天蝎 | 陷 | 情绪强烈深沉，难以安放；执念重，爱恨浓烈，安全感来自深度掌控和绝对信任 |
| 射手 | — | 情绪乐观豁达，内心向往自由和探索；情绪来得快去得快，需要空间和新鲜感 |
| 摩羯 | 弱 | 情绪压抑克制，不易流露柔软；安全感来自成就和掌控，内心责任感和孤独感重 |
| 水瓶 | — | 情绪理性疏离，内心需要独立空间；情感表达含蓄，共情方式偏理性和理想化 |
| 双鱼 | — | 情绪极度敏感，共情力近乎无边；感性浪漫，容易受他人情绪感染，需要灵性安放 |
