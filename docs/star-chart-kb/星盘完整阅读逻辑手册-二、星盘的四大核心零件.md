## 二、星盘的四大核心零件

读懂星盘，只需要搞懂四件事：

| 零件 | 对应问题 | 大白话 |
|------|----------|--------|
| **行星** | 你心里**想要什么** | 内在驱动力 / 人格模块 |
| **星座** | 你习惯**怎么干** | 性格风格 / 表达方式 |
| **宫位** | 这件事发生在**哪** | 人生领域 / 生活场景 |
| **相位** | 两股能量**相处得怎么样** | 能量互动 / 顺逆难易 |

### ✅ 万能解读公式

> **行星（动力） + 星座（风格） + 宫位（领域） + 相位（互动） = 完整解读**
