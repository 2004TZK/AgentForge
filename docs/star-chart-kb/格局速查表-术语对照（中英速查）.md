## 术语对照（中英速查）

| 中文术语 | 英文 | 别称 | 一句话释义 |
|----------|------|------|-----------|
| 大三角 | Grand Trine | 大三角格局 | 三星互拱，天赋流淌 |
| T三角 | T-Square | T型三角、刑冲三角 | 冲+双刑，张力驱动 |
| 大十字 | Grand Cross / Grand Square | 大十字格局 | 四刑双冲，多向拉扯 |
| 星群 | Stellium | 聚星、星团 | 三星+同座/同宫，聚焦 |
| 风筝 | Kite | 风筝格局 | 大三角+对冲，天赋有出口 |
| 神秘长方形 | Mystic Rectangle | 神秘矩形 | 双冲+拱+六合，对中有通 |
| 上帝之指 | Yod | 命运之指、手指 | 双梅花+六合，使命牵引 |
| 摇篮 | Cradle | 摇篮格局 | 双六合+双拱+冲，潜能储备 |
| 大六分相 | Grand Sextile | 大卫之星 | 六六合，极和谐极罕见 |
| 碗型 | Bowl | 碗型分布 | 半圆集中，渴望补全 |
| 瓮型 | Bucket | 桶型、瓮型 | 半圆+把手星，焦点出口 |
| 火车头型 | Locomotive | 火车头分布 | 三分之二集中，轨道推进 |
| 跷跷板型 | See-Saw | 跷跷板分布 | 两极分布，来回摆荡 |
| 撒型 | Splash | 散布型 | 均匀散布，通才型 |
| 扇型 | Splay | 扇骨型 | 三组鼎立，多元并行 |
| 束型 | Bundle | 捆型 | 三分之一集中，窄而深 |

> **相位角度速查**：合 0° · 六合 60° · 刑 90° · 拱 120° · 梅花 150° · 冲 180°。详见《星盘完整阅读逻辑手册》第六章"认识相位"。
