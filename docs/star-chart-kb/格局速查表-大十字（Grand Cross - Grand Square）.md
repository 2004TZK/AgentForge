## 大十字（Grand Cross / Grand Square）

| 属性 | 说明 |
|------|------|
| **结构** | 四颗行星构成一个正方形，两两之间成 90° 刑相，同时有两组 180° 对冲 |
| **元素** | 四颗行星落在同一品质（开创/固定/变动）的四个星座 |
| **性质** | 高压、多向拉扯、十字路口型 |
| **含义** | 大十字代表四股力量同时拉扯，盘主在多个方向上承受压力。能量被夹在十字路口中央，每个方向都在拉、每条路都不好走。但这恰恰是一种极强的历练：被迫学会平衡多方力量，在持续的矛盾中淬炼出超常的综合能力。 |
| **解读要点** | 1) 确认是哪种品质的大十字：开创型大十字主行动力与启动、固定型大十字主执着与坚守、变动型大十字主适应与流转；2) 看四颗行星分别代表什么、落在哪四个宫位，四条拉扯的线索分别指向哪些人生领域；3) 大十字的能量需要"找到重心"——不是消除矛盾，而是在矛盾中站住脚；4) 涉及角宫（1/4/7/10）的大十字对整盘影响极大，几乎贯穿一生。 |
| **柔和提示** | 不要说"你四面楚歌、处处受困"，而说"你同时在好几个领域面临课题，这些课题会把你磨练成一个综合能力很强的人"。 |
