## 四、古典守护与现代守护对照

> 在现代占星（20 世纪后）中，三颗外行星被分配了守护星座，与古典守护星形成"双守护"关系。解读时古典守护星与现代守护星的含义可互为补充。

| 星座 | 古典守护星 | 现代守护星 | 说明 |
|------|-----------|-----------|------|
| 白羊 | 火星 | 火星 | 无变更 |
| 金牛 | 金星 | 金星 | 无变更 |
| 双子 | 水星 | 水星 | 无变更 |
| 巨蟹 | 月亮 | 月亮 | 无变更 |
| 狮子 | 太阳 | 太阳 | 无变更 |
| 处女 | 水星 | 水星 | 无变更 |
| 天秤 | 金星 | 金星 | 无变更 |
| 天蝎 | 火星 | 冥王星 | 现代增补冥王星 |
| 射手 | 木星 | 木星 | 无变更 |
| 摩羯 | 土星 | 土星 | 无变更 |
| 水瓶 | 土星 | 天王星 | 现代增补天王星 |
| 双鱼 | 木星 | 海王星 | 现代增补海王星 |

> **解读提示**：分析空宫（无行星落入的宫位）时，看该宫宫头星座的守护星落在哪个宫位、状态如何，即可推断该宫位的主题如何被"代理"发挥。若该星座有现代守护星，可同时参考古典与现代守护星，古典守护偏传统根基，现代守护偏时代特质。
