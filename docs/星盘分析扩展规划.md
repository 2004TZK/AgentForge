## 1. V2 功能（独立迭代 · ✅ 已交付）

| 功能 | 说明 | 交付（2026-08-05） | 状态 |
|---|---|---|---|
| 行运（Transits） | 当天行星与本命盘的互动 → "近期运势" | `transit_chart` 工具（`app/tools/star_transit.py`）：行运行星位置（含落本命宫）+ 行运对本命行星/四轴相位；transitDate/transitTime 缺省当前时刻 | ✅ |
| 推运（Progressions） | 年龄推运解读 | `progression_chart` 工具（`app/tools/star_progression.py`）：次限推运（一天=一年），age 或 targetDate；推运行星（落本命宫）+ 推运四轴 + 推运内部/对本命相位 | ✅ |
| 合盘（Synastry） | 两个人的星盘关系分析 | `synastry_chart` 工具（`app/tools/star_synastry.py`）：A/B 两方本命盘 + 合盘相位（A×B）+ 落宫叠加（A 入 B 宫 / B 入 A 宫）+ 行星×对方四轴 | ✅ |
| 择时（Electional） | 选日子 | `electional_chart` 工具（`app/tools/star_electional.py`）：startDate + days（默认 7，上限 60），可选本命盘个人择时；启发式相位评分输出 Top 候选 + 最佳日期 | ✅ |
| 报告导出 | 生成 Markdown/PDF 星盘报告 | `app/services/star_report.py`（Markdown/PDF 分节渲染）+ `POST /star-chart/report` 接口（内部鉴权）；前端排盘卡片「导出 MD / 打印·PDF」按钮（`agentforge-web/src/utils/starReport.ts`） | ✅ |

> 说明：V2 计算工具复用 M1 共享底座 `app/tools/star_base.py`（时间/历书/城市/相位/宫位），口径与 V1 一致（Tropical + Geocentric + Placidus 默认、可整宫制/恒星黄道）；四工具均注册进 `registry.py`（`result_max=None` 不截断），并绑定「星盘分析师」智能体（`docker/mysql/init/02-data.sql` agent_tool id=4~7）。

## 3. 拆分原则与边界

- **V1 固定范围**：本命盘排盘（十行星/四轴/宫位/相位）+ LLM 解读，口径遵循主设计文档（黄道类型、宫位制、时区处理、免责声明）。
- 扩展项不进入 V1 验收；若后续提前实现某项，需先更新主设计文档对应章节并保持口径一致。
- 知识库文档集（手册 + 宫位解析 + 落座速查 + 守护星座表 + 格局速查）的缺失项已全部补齐：《行星守护星座表》《格局速查表》《行星落座速查表》均已创建，是 M3 知识库入库的前置任务，不阻塞 V1。

- 测试：`tests/test_star_v2.py`（24 项）+ `tests/test_star_report.py`（11 项）；全量 277 passed / 3 skipped

**前端（agentforge-web）**

- `src/stores/chat.ts`：transit_chart / progression_chart 结果同样渲染排盘卡片（顶层字段与本命盘一致）
- 测试：`src/utils/__tests__/starReport.spec.ts`（4 项）；`npm run build` 通过

**智能体与数据**
- `docker/mysql/init/02-data.sql`：「星盘分析师」（agent 4）绑定 transit_chart / progression_chart / synastry_chart / electional_chart（agent_tool id=4~7）；系统提示词新增「V2 扩展能力」节
- `docs/星盘分析师系统提示词.md`：同步 V2 工具指引（v0.2）

**口径与边界**
- 行运/推运/合盘：Tropical + Geocentric + Placidus（默认），可整宫制/恒星黄道；相位容许度与 V1 一致
- 次限推运：一天=一年（推运儒略日 = 本命儒略日 + 年龄天数）
- 择时：按日粗筛启发式评分（拱/六合 +1、刑/冲 -1、合相 0；快速行星权重 1.0、慢速 0.5；对日月升权重 2.0），仅供参考，非"标准答案"
- 报告：Markdown/PDF 均由结构化分节渲染，统一附免责声明与生成时间
