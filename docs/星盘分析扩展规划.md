# 星盘分析扩展规划（V2 与可选增强项）

> 状态：评审修订中 · 版本：v0.1 · 日期：2026-08-04
> 说明：本文档从《星盘分析功能设计》v0.5 拆分而来，集中管理原 5.2 节及各章节标注的"可选/增强"项。**V1 只做本命盘分析（排盘 + LLM 解读），以下内容均不进入 V1。**

---

## 1. V2 功能（独立迭代）

| 功能 | 说明 | 依赖与备注 |
|---|---|---|
| 行运（Transits） | 当天行星与本命盘的互动 → "近期运势" | 需当前时间输入；相位计算可复用 V1 |
| 推运（Progressions） | 年龄推运解读 | 与行运共用时间推进逻辑 |
| 合盘（Synastry） | 两个人的星盘关系分析 | 需支持多个出生信息输入 |
| 择时（Electional） | 选日子 | 依赖行运/推运能力 |
| 报告导出 | 生成 Markdown/PDF 星盘报告 | 前端/文档生成 |

## 2. 可选增强（M3 及以后）

| 增强项 | 说明 | 归属 |
|---|---|---|
| 深度分析工作流 | 一键生成完整报告：`tool 排盘（birthText={message}）` → `llm 分维度解读` → `llm 汇总报告`，节点日志可查（主文档 6.3） | M3 |
| 占星知识库 | RAG 文档集：《星盘完整阅读逻辑手册》（方法论）+《星盘宫位完整解析》（12 宫 × 星体落宫）+《行星落座速查表》（10 行星 × 12 星座落座）+ 行星守护星座表 + 格局速查表（主文档 6.4） | M3 |
| 前端排盘卡片（增强版） | V1 已做基础表格卡片（主文档 6.5）；本项为增强版（可含黄道圈示意图/交互）；当前 SSE `tool` 事件 result 为字符串且截断 120 字符，需前端解析或事件携带结构化字段 | M3 |
| 黄道圈星盘图 | 可视化星盘；配色可参考手册相位约定（合=白/黄、拱=绿、六合=蓝、刑=红、冲=紫红） | V2 |
| 恒星黄道（Sidereal） | 主文档 3.3 可选配置，需指定 Ayanamsa（默认 Lahiri）；注意星座归属可能与回归黄道相差近一个星座 | V2 |
| 在线地理编码 | 接入 Nominatim，任意地点自动解析经纬度；当前以城市库 + 手动经纬度兜底（主文档 4 节） | 视城市库覆盖情况 |

## 3. 拆分原则与边界

- **V1 固定范围**：本命盘排盘（十行星/四轴/宫位/相位）+ LLM 解读，口径遵循主设计文档（黄道类型、宫位制、时区处理、免责声明）。
- 扩展项不进入 V1 验收；若后续提前实现某项，需先更新主设计文档对应章节并保持口径一致。
- 知识库文档集（手册 + 宫位解析 + 落座速查 + 守护星座表 + 格局速查）的缺失项已全部补齐：《行星守护星座表》《格局速查表》《行星落座速查表》均已创建，是 M3 知识库入库的前置任务，不阻塞 V1。
