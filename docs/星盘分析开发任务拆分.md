## 4. 风险与注意事项

- **本地开发环境**：pyswisseph 无 cp312 Windows wheel，本地验证用 Python 3.11（`.tmp/py311`）或 Docker 3.12；勿在 3.12 本地强装。
- **许可**：pyswisseph 为 AGPL-3.0（Swiss Ephemeris 双许可），MIT 仓库引入需在依赖文档声明；历书数据保留 COPYRIGHT.txt。
- **解读质量**：提示词（六步顺序+误区约束）+ 知识库双保险；解读非"标准答案"，风格可调。
- **前端截断**：SSE `tool` 事件 result 为字符串且展示截断 120 字符，做卡片需结构化字段或前端解析。
- **城市库范围**：仅中国城市（223 条）；非中国出生地需经纬度 + IANA 时区。
- **并发安全**：pyswisseph 的 `set_sid_mode` 全局状态见 M2.6.1。

## 5. 建议执行顺序

M2 阶段按依赖推进：**M2.1 提示词 → M2.2 种子数据 → M2.3 端到端验证（主链路→追问→失败→边界→稳定性）→ M2.4 演示文档**；M2.5 卡片与 M2.6 并发检查可并行。

M3 阶段：**M3.1 工作流 → M3.2 知识库入库 → M3.3 增强卡片**。
