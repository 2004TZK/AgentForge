## 1. 功能定位

一句话：**输入出生信息 → 自动排盘（计算） → 基于星盘数据生成解读（LLM）**。

面向场景：

- 演示：给面试官/朋友演示"专业 AI 应用"（工具调用 + 确定性计算 + LLM 生成）
- 使用：占星爱好者快速获得一份本命盘分析
- 技术亮点：天文计算工具 + ReAct 工具循环 + 结构化输出，是求职项目里很好的差异化功能

---

## 2. 核心认知：星盘分析 = 计算 + 解读

| 环节 | 性质 | 由谁完成 |
|---|---|---|
| 排盘计算（行星位置、宫位、相位） | 确定性天文计算，LLM 算不准 | 新增 `star_chart` 工具（天文历书库） |
| 解读（性格、事业、情感等） | 生成式自然语言 | LLM（qwen3.7-plus） |
| 知识支撑（宫位/相位/星座含义） | 检索增强 | RAG 知识库（可选） |
| 多步骤流程（排盘 → 分析 → 报告） | 流程编排 | Workflow 工作流（可选） |

> 关键结论：**项目现有架构完全能承载这套逻辑**——工具调用机制（calculator 同款）负责计算，Agent + LLM 负责解读，缺的只是一块"排盘计算工具"。

## 3. 输入与前置条件

### 3.1 必需输入

| 字段 | 说明 | 要求 |
|---|---|---|
| 出生日期 | 公历 | 必填，格式 `YYYY-MM-DD` |
| 出生时间 | 具体到分钟 | 必填；影响上升点与宫位，越准越好 |
| 出生地点 | 城市名 或 经纬度 | 二选一；**city 优先**（可推断时区与夏令时），城市不在库时用手动经纬度；两者同时提供时以 city 为准（忽略经纬度或校验一致性） |
| 时区 | IANA 时区名（如 `Asia/Shanghai`） | 城市名输入时由城市库自动推断；**直接输入经纬度时必填**（经纬度无法推导时区与历史夏令时） |

> 出生地点由用户主动提供（城市名或经纬度）；系统**不自动定位、不推断用户地理位置**。

### 3.2 可选输入

- 姓名/称呼：仅用于报告开头称呼，不影响计算
- 性别：不参与计算，仅用于文案用词（可默认不启用）
- 时区与夏令时：默认按出生城市自动推断（城市库内置 IANA 时区映射），允许手动覆盖；当地时转 UTC 使用 `zoneinfo` + `tzdata` 处理历史夏令时规则

### 3.3 配置项（Agent 或工具级）

- 宫位制：默认 **Placidus**，可切换 **整宫制（Whole Sign）**
- 黄道类型：默认 **回归黄道（Tropical）**；可选 **恒星黄道（Sidereal）**（需指定 Ayanamsa，默认 Lahiri）。两种口径下星座归属可能相差近一个星座，必须显式配置并在输出中标注
- 相位容许度：默认标准（合相 8°、对分 8°、三分 8°、四分 8°、六分 6°）
- 相位范围：V1 仅计算五大主相位，且仅行星间相位（暂不含 ASC/MC 相位）；容许度 V1 使用统一值，暂不做星体差异允许度
- 格局判定：**patterns（大三角、T 三角、星群等）由 `star_chart` 工具基于相位表计算输出，LLM 只解读不判定**
- 是否包含三王星（天王/海王/冥王）：默认包含

## 4. 计算引擎选型

| 方案 | 说明 | 取舍 |
|---|---|---|
| **pyswisseph**（瑞士星历表） | 占星界行业标准，精度高，支持各种宫位制/恒星黄道 | **已实现（V1 唯一引擎）**，AGPL-3.0 |
| **flatlib**（纯 Python） | 轻量、内置历书数据，常用行星与宫位够用 | **V1 不纳入**：双引擎测试成本高、收益低，如需可后续补充 |

决策：**V1 仅实现 pyswisseph 单引擎**（历书数据随仓库提交），排盘失败以可读报错兜底；flatlib 双引擎兜底不在 V1 验收范围。

> **许可注意**：pyswisseph 采用 AGPL-3.0（Swiss Ephemeris 官方为双许可：AGPL-3.0 或商业许可）；历书数据文件**不随 pip 包附带**，需单独从 Astrodienst 官方下载，且数据文件需保留版权声明。本项目为 MIT 开源，引入前需在依赖/许可文档中声明这一差异（自托管公开 Demo 可接受，但面试展示时大概率会被问到）。
> **数据体积（已落地）**：采用精简版历书 `sepl_18.se1` + `semo_18.se1`（覆盖 1800-2399，合计约 1.8MB），已下载并随仓库提交（`app/tools/data/ephe/`，含 COPYRIGHT.txt 许可声明）；全量约 97MB，不采用。Docker 构建经 `COPY . .` 打包，`scripts/download_ephemeris.py` 可重新下载。

### 地点 → 经纬度

- 系统**不自动定位用户位置**：经纬度换算仅在用户提供城市名后由工具完成（城市库查找），城市不在库时请用户直接提供经纬度
- **城市库已实现**：223 条中国城市（大陆 210 + 香港 3 + 澳门 2 + 台湾 8），数据源 GeoNames（权威坐标/人口/时区），字段 `zh / en / country / lat / lng / tz`（`app/tools/data/cities.json`，`scripts/build_cities.py` 可复现）
- 时区映射：中国大陆统一 `Asia/Shanghai`，乌鲁木齐为 `Asia/Urumqi`（其余新疆城市 GeoNames 口径亦为 `Asia/Shanghai`）；港澳台分别为 `Asia/Hong_Kong / Asia/Macau / Asia/Taipei`
- 支持直接输入经纬度（兜底，不依赖外部地理 API，避免限流）；此时**必须额外提供时区**（见 3.1）
- 后续可选接入 Nominatim 免费地理编码（见《星盘分析扩展规划》）

## 5. 功能清单

### 5.1 V1：本命盘分析（核心）

**排盘计算输出（结构化 JSON）：**

- 口径元数据：黄道类型（tropical/sidereal）、宫位制、历书模式、时区（用于验收核对与差异排查）
- 十大星体/点体：太阳、月亮、水星、金星、火星、木星、土星、天王星、海王星、冥王星
- 四轴：上升 ASC、天顶 MC、下降 DESC、天底 IC
- 每个星体：所在星座、度数、所在宫位、黄道经度
- 相位表：合相/六分/四分/三分/对分，含容许度内判定的相位与精确度
- 格局 patterns（已实现）：大三角、T 三角、大十字、星群（同宫/同星座），由工具计算，LLM 仅负责解读
- 宫位表：12 宫起始度数 + 宫内星体

**LLM 解读输出（自然语言）：**

1. 星盘总览：整体能量基调、核心性格标签（3-5 个），并简述四轴（ASC/MC/DES/IC）方向
2. 上升星座与外在形象
3. 太阳/月亮/水星/金星/火星重点解读（落座 × 落宫）
4. 宫位重点：人生领域侧重（2-3 个重点宫位）
5. 关键相位：挑最显著的 3-5 个相位解读（紧张相位 = 成长课题，和谐相位 = 天赋）
6. 格局提示：基于工具输出的 patterns 解读（若有：大三角、T 三角、星群等）
7. 小结与建议
8. 免责声明：仅供娱乐与自我探索参考

### 5.2 V2 与可选增强（拆分至独立文档）

V1 不实现的扩展项已拆分至独立文档《星盘分析扩展规划》（`docs/星盘分析扩展规划.md`），包括：行运/推运/合盘/择时/报告导出（V2），以及深度分析工作流、占星知识库、前端排盘卡片与黄道圈图、恒星黄道、在线地理编码（M3/可选增强）。

## 6. 与现有项目的结合方式

### 6.1 工具：`star_chart`（核心新增）

沿用现有工具注册表机制（`app/tools/registry.py`），LLM 依据 Schema 自动调用，前端 SSE 实时展示工具活动。

> **实现状态（已落地）**：`star_chart` 已完成并注册进 `registry.py`（`result_max=None`，返回完整排盘 JSON、不被 500 字符截断）；入参支持结构化字段与 `birthText` 自由文本；出参含 `meta`（zodiac / houseSystem / houseSystemFallback / timezone / ephemeris / ayanamsa / birthDateTime / utDateTime）、`planets`（含 house / retrograde）、`houses`（cusp / sign / planets）、`aspects`、`patterns`。

```json
// 入参示例
{
  "birthDate": "1994-05-20",
  "birthTime": "14:30",
  "city": "北京",                 // city 优先；经纬度仅作城市不在库时的兜底
  "latitude": 39.9042,           // 与 city 同时提供时以 city 为准（忽略经纬度）
  "longitude": 116.4074,
  "timezone": "Asia/Shanghai",   // 城市在库时可省略，自动推断
  "houseSystem": "placidus"
}
```

```json
// 出参示例（节选）
{
  "meta": {"zodiac": "tropical", "houseSystem": "placidus", "timezone": "Asia/Shanghai", "ephemeris": "pyswisseph"},
  "ascendant": {"sign": "天秤座", "degree": 12.5, "longitude": 192.5},
  "planets": {
    "sun":     {"sign": "金牛座", "house": 9, "degree": 29.4, "longitude": 59.4},
    "moon":    {"sign": "双子座", "house": 10, "degree": 3.8, "longitude": 63.8},
    "mercury": {"sign": "双子座", "house": 10, "degree": 15.2, "longitude": 75.2}
  },
  "aspects": [
    {"p1": "sun", "p2": "moon", "type": "三分相", "orb": 4.4},
    {"p1": "sun", "p2": "saturn", "type": "四分相", "orb": 1.9}
  ],
  "houses": {                    // 节选：完整 12 宫结构相同
    "1": {"cusp": 192.5, "planets": []},
    "9": {"cusp": 59.4, "planets": ["sun"]},
    "10": {"cusp": 63.8, "planets": ["moon", "mercury"]}
  },
  "patterns": [                  // 由工具基于完整相位表判定，LLM 只解读
    {"type": "星群", "scope": "house", "house": 10, "planets": ["moon", "mercury"]}
  ]
}
```

工具同时接受自由文本 `birthText`（如 `"1994-05-20 14:30 北京"`），供工作流节点直接传用户消息（见 6.3）。

### 6.2 智能体：星盘分析师

- 名称：星盘分析师
- 系统提示词要点：
- 人设：资深占星师，理性、温和、具体
- 流程：**先调用 `star_chart` 排盘，拿到真实数据再解读；未拿到数据不凭空解读**
- 获取输入：进入对话即向用户询问出生日期/时间/地点；**不自动定位、不推断用户地理位置**（无定位、无 IP 推断），直接请用户提供出生城市名或经纬度
- 方法论：解读严格遵循《星盘完整阅读逻辑手册》的阅读顺序与万能公式（见 6.6），不跳步、不罗列，输出有逻辑的完整故事；同时遵守手册"常见误区"清单的负面约束（不只看太阳星座、不把刑冲说成厄运、空宫不等于空白）
  - 规范：引用具体行星/宫位/相位；不夸大、不恐吓；注明"娱乐与自我探索参考"；篇幅：单次完整解读 800-1200 字
  - 追问：支持"那我事业运呢？"等基于记忆的多轮追问；追问时若记忆中有出生信息，须**先重新调用 `star_chart` 排盘再解读**（排盘为确定性计算，重复调用结果一致），信息缺失则先追问补齐
- 绑定工具：`star_chart`
- 模型：qwen3.7-plus（现有）

### 6.3 工作流：星盘深度报告（可选）

节点：`tool 排盘（birthText={message}）` → `llm 分维度解读` → `llm 汇总报告`

> 衔接说明：当前工作流引擎的 llm 节点输出为自由文本，不具备结构化字段提取能力，因此**不设"llm 提取出生信息"节点**；`star_chart` 需支持自由文本参数 `birthText`（如 `"1994-05-20 14:30 北京"`），工作流直接以用户消息作为 `{message}` 传入排盘节点。若后续引擎支持 LLM 结构化输出（JSON 解析入变量），可再拆出提取节点。

好处：一次性输出完整报告，流程可复现、可看节点日志，演示效果好。

### 6.4 知识库：占星资料（可选增强）

知识库文档集：《星盘完整阅读逻辑手册》（解读方法论，见 6.6）+《星盘宫位完整解析》（12 宫 × 星体落宫速查，见 6.6）+《行星落座速查表》（10 行星 × 12 星座落座速查，补齐 5.1 输出第 3 项"日月水金火重点解读（落座 × 落宫）"中落座维度）+《行星守护星座表》（守护/旺/弱/陷对照）+《格局速查表》（相位格局与分布格局含义速查），让解读更专业、减少凭空发挥。

### 6.5 前端

- **V1 不需要新页面**：直接在聊天页输入出生信息即可；**V1 将工具返回的星盘 JSON 渲染为基础表格卡片**（成本低、演示效果好）
- **M3 增强版卡片**：可含黄道圈示意图/交互。注意：当前 SSE `tool` 事件的 result 为字符串且前端展示截断至 120 字符，做卡片需前端解析 JSON 或让工具事件携带结构化字段

### 6.6 解读方法论：星盘完整阅读逻辑（知识底座）

解读层不依赖 LLM 自由发挥，遵循固定方法论《星盘完整阅读逻辑手册》（全文见**附录 A**；独立副本 `docs/星盘完整阅读逻辑手册.md` 为知识库入库源，两处内容不一致时以独立副本为准）。

**万能解读公式**：行星（内在驱动力）+ 星座（表达风格）+ 宫位（人生领域）+ 相位（能量互动）= 完整解读

**固定阅读顺序（LLM 解读流程骨架）**：

| 步骤 | 内容 | 对应 5.1 输出 |
|---|---|---|
| 1 定格局 | 四轴：ASC（外在形象）/ MC（事业）/ DES（伴侣类型）/ IC（原生家庭） | 上升星座与外在形象 |
| 2 看个人行星 | 日月水金火：落座 × 落宫 × 相位 | 太阳/月亮/水星/金星/火星重点解读 |
| 3 看外行星 | 木土天海冥：**落宫优先于落座**（时代共性） | 宫位重点（辅助） |
| 4 看相位 | 先个人行星间相位，再外行星×个人行星；重点日月金火土木 | 关键相位 |
| 5 看宫位分布 | 上下半盘（1-6 自我 / 7-12 他人社会）、左右半盘、空宫看宫头守护星 | 宫位重点 |
| 6 综合串联 | 讲完整人生故事：性格 / 事业 / 感情 / 原生家庭 / 课题 / 幸运点 | 星盘总览 + 小结与建议 |

**双重落地方式**：

1. **系统提示词骨架**：阅读顺序 + 常见误区清单（❌ 只看太阳星座 / 凶相位=倒霉 / 空宫=空白）直接约束 LLM 的解读结构与用词，防止跳步、罗列和恐吓式表述
2. **RAG 知识库主文档**：手册含行星/星座/宫位/相位速查表与阅读逻辑，结构化程度高、适合切片检索；宫位细节（12 宫 × 星体落宫）以《星盘宫位完整解析》为检索来源（6.4）

**审查备注（收录时需注意）**：

- 手册的万能公式（行星 + 星座 + 宫位 + 相位）依赖 LLM 现场组合"行星 × 星座"释义，效果不稳定；**已补《行星落座速查表》（10 行星 × 12 星座 = 120 条预制释义）**，与《星盘宫位完整解析》（落宫）搭配即可拼出"行星 + 星座 + 宫位"三段组合，大幅降低 LLM 组合漂移
- 手册引用"宫头守护星/守护关系"，但未含行星守护星座表；**已补《行星守护星座表》**（守护/旺/弱/陷对照，`docs/行星守护星座表.md`），空宫解读已可落地
- 手册未覆盖**格局**；格局**判定**已由 `star_chart` 输出 patterns（大三角/T 三角/大十字/星群，见 5.1/6.1），**含义速查已补《格局速查表》**（`docs/格局速查表.md`）供 LLM 解读
- 手册左右半盘把 6/12 宫同时列入两侧（标准划分：左侧 = 12-1-2-3-4-5，右侧 = 6-7-8-9-10-11），属简化写法，解读提示词可自行修正
- 手册 10 宫写"母亲"、4 宫写"父母"，传统上 4/10 宫与父母的对应存在多种说法，建议提示词弱化单一断言
- 手册未提逆行/月亮交点/容许度，与 V1 范围一致（V1 不含这些），无需补齐
- 手册的相位配色约定（合=白/黄、拱=绿、六合=蓝、刑=红、冲=紫红）可直接用于 V2 黄道圈可视化
- 《星盘宫位完整解析》含健康类描述（如 6 宫肠胃/睡眠/慢性病）与 12 宫"凶宫"表述，仅作象征性参考；LLM 解读须柔和化并避免医疗断言（与 6.2"不夸大、不恐吓"一致）

## 7. 错误处理与边界

| 场景 | 处理 |
|---|---|
| 缺出生时间 | 提示需要时间，且说明"没有时间只能看太阳星座，宫位不准确" |
| 城市不在库中 | 提示改用经纬度输入 |
| 手动经纬度缺时区 | 提示补充 IANA 时区（经纬度无法推导时区/历史夏令时） |
| 城市与经纬度同时提供且不一致 | 以 city 为准（忽略经纬度）；必要时提示校验 |
| 经纬度非法 | 参数校验 + 可读报错 |
| Placidus 高纬度计算失败（无宫头） | 自动降级整宫制并在结果中标注 `houseSystemFallback: true`；或返回可读错误 |
| pyswisseph 未安装 | 返回可读错误"请执行 pip install pyswisseph tzdata"（工具懒加载，不影响应用启动） |
| 历书数据缺失 | 启动时预置/自动下载，失败提示明确 |
| 年份超出历书覆盖（<1800 或 >2399） | 友好提示（历书精简版覆盖 1800-2399） |

## 8. 限制与注意事项（关于"完美"的边界）

- **计算精度**：瑞士星历表精度高，但前提是出生时间准确；时间差 10 分钟可能让上升点偏移数度
- **时区与夏令时**：当地时转 UTC 依赖正确时区；城市名走城市库内置 IANA 时区，手动经纬度必须显式提供时区，否则排盘可能整体偏移
- **宫位制差异**：Placidus 与整宫制在极端纬度/高纬度地区宫位差异大，解读会不同；且极地附近 Placidus 无宫头会计算失败，需降级整宫制或报错（见第 7 节）
- **占星科学性**：占星存在争议，产品内必须注明"娱乐/自我探索参考"
- **LLM 解读质量**：受提示词与知识库影响，风格可调，但非"标准答案"
- **城市库覆盖**：小城市需手动经纬度兜底

## 附录 A：星盘完整阅读逻辑手册（全文）

> 本附录为《星盘完整阅读逻辑手册》全文副本，用于功能设计/开发自包含参考；独立文件 `docs/星盘完整阅读逻辑手册.md` 为知识库入库源，两处内容不一致时以独立文件为准。

### A.1 星盘是什么

**本命星盘 = 你出生那一瞬间，以出生地为视角拍下的一张星空快照。**

排盘三要素：
- 出生日期（年月日）
- 出生时间（精确到分钟，越准越好）
- 出生城市（用于计算经纬度）

> 大家常说的"太阳星座"（几月几号是什么座）只是星盘中太阳一颗星体的落座，只占全部信息的一小部分。

**星盘的本质**：不是宿命判决，而是你先天自带的性格蓝图、天赋倾向、软肋课题和人生领域的能量分布地图。

### A.2 星盘的四大核心零件

读懂星盘，只需要搞懂四件事：

| 零件 | 对应问题 | 大白话 |
|------|----------|--------|
| **行星** | 你心里**想要什么** | 内在驱动力 / 人格模块 |
| **星座** | 你习惯**怎么干** | 性格风格 / 表达方式 |
| **宫位** | 这件事发生在**哪** | 人生领域 / 生活场景 |
| **相位** | 两股能量**相处得怎么样** | 能量互动 / 顺逆难易 |

**万能解读公式**：

> **行星（动力） + 星座（风格） + 宫位（领域） + 相位（互动） = 完整解读**

### A.3 第一步：认识十颗行星（内在驱动力）

每颗行星代表你人格中的一个独立模块：

| 行星 | 核心关键词 | 代表什么 |
|------|-----------|----------|
| **太阳** | 自我、意志、人生追求 | 你的核心身份、想成为什么样的人 |
| **月亮** | 情绪、安全感、潜意识 | 内心深处的需求、情绪反应模式 |
| **水星** | 思维、沟通、学习 | 怎么想、怎么说、怎么接收信息 |
| **金星** | 审美、恋爱、人缘、喜好 | 喜欢什么、怎么爱、怎么花钱 |
| **火星** | 行动力、脾气、欲望 | 怎么争取、怎么发火、性驱力 |
| **木星** | 好运、扩张、机遇、贵人 | 哪里容易顺、哪里容易膨胀 |
| **土星** | 压力、限制、磨难、课题 | 哪里容易卡、哪里需要苦修 |
| **天王星** | 叛逆、创新、突发变动 | 哪里容易出其不意、哪里求新 |
| **海王星** | 幻想、敏感、逃避、灵性 | 哪里容易迷糊、哪里有共情天赋 |
| **冥王星** | 执念、控制、重生、深层恐惧 | 哪里执念最深、哪里会彻底蜕变 |

**个人行星 vs 外行星**：
- 个人行星（日月水金火）：直接影响你的日常性格
- 外行星（木土天海冥）：走得慢，影响一代人的共同特质，落宫比落座更重要

### A.4 第二步：认识十二星座（性格风格）

12星座是能量的"表达方式"，决定行星以什么风格运作。

**三种属性（三分法）**：

| 属性 | 关键词 | 星座 | 特点 |
|------|--------|------|------|
| **火象** | 行动、热情、直接 | 白羊、狮子、射手 | 先做再想，行动力强 |
| **土象** | 务实、稳定、物质 | 金牛、处女、摩羯 | 脚踏实地，重视结果 |
| **风象** | 思维、社交、信息 | 双子、天秤、水瓶 | 理性思考，爱交流 |
| **水象** | 情感、直觉、深层 | 巨蟹、天蝎、双鱼 | 敏感细腻，靠感受 |

**三种模式（四分法）**：

| 模式 | 关键词 | 星座 | 特点 |
|------|--------|------|------|
| **开创（基本）** | 发起、开端、行动 | 白羊、巨蟹、天秤、摩羯 | 喜欢开头，主动启动 |
| **固定** | 稳定、执着、维持 | 金牛、狮子、天蝎、水瓶 | 坚持到底，不易改变 |
| **变动** | 适应、灵活、过渡 | 双子、处女、射手、双鱼 | 灵活变通，善于调整 |

> 记忆口诀：开创=点火的人，固定=烧到底的人，变动=传火的人。

| **变动宫（果宫）** | 3、6、9、12 | 思维、日常、流动、潜意识 |

**四轴（四个最重要的宫位起点）**：

### A.6 第四步：认识相位（能量互动）

相位是两颗行星之间的夹角关系，代表两股能量是合拍、冲突还是拉扯。

**五大主相位**：

| 相位 | 角度 | 颜色（常见） | 性质 | 一句话 |
|------|------|-------------|------|--------|
| **合相** | 0° | 白/黄 | 中性偏强 | 两股能量绑在一起，同进同退 |
| **拱相（三分相）** | 120° | 绿 | 吉 | 天生天赋，顺水推舟 |
| **六合（六分相）** | 60° | 蓝 | 吉 | 外部机遇，主动可得 |
| **刑相（四分相）** | 90° | 红 | 凶（挑战） | 内心冲突，需要修炼的课题 |
| **对冲（对分相）** | 180° | 紫/红 | 凶（拉扯） | 两难摇摆，外界带来的对立 |

**相位记忆口诀**：

> 绿线拱 = 天生天赋，顺手省心
> 蓝线六合 = 等待机遇，主动去拿
> 白线合相 = 能量合并，一体两面
> 红线刑克 = 内心矛盾，需要修行
> 紫线对冲 = 两难拉扯，来回纠结

**重要观念**：

- **和谐相位多**：人生安逸顺遂，但容易安于现状、缺少成长动力
- **压力相位多**：一生充满考验，但熬过之后心智、能力远超常人
- **刑冲不是厄运**，是逼迫你成长的课题；天赋也可能因为太顺而荒废

### A.7 完整读盘步骤（实操流程）

按这个顺序读，不会乱、不会漏：

**第1步：定格局 —— 看四轴和整体分布**

先看星盘的"骨架"：
1. **上升星座（ASC）**：外在性格、第一印象、外貌气质
2. **天顶星座（MC）**：事业方向、社会形象
3. **下降星座（DES）**：吸引的伴侣类型
4. **天底星座（IC）**：原生家庭模式、内心安全感来源

> 四轴是星盘的四个"锚点"，先定大方向再看细节。

**第2步：看个人行星 —— 日月水金火**

逐个看五颗个人行星的落座和落宫，这是你最核心的性格：

| 行星 | 重点看什么 |
|------|-----------|
| 太阳 | 你的核心自我、人生主线 |
| 月亮 | 你的情绪模式、安全感来源 |
| 水星 | 你的思维方式、沟通风格 |
| 金星 | 你的恋爱模式、审美偏好 |
| 火星 | 你的行动方式、脾气爆发点 |

> 对每颗行星都套用公式：**行星 + 星座 + 宫位 = 这颗星在哪个领域、以什么风格运作**

**第3步：看外行星 —— 木土天海冥**

外行星走得慢，**落宫比落座更重要**：
- **木星落宫**：你哪个领域容易有好运、机遇
- **土星落宫**：你哪个领域压力最大、需要苦修
- **天王星落宫**：你哪个领域容易突发变动、求新求变
- **海王星落宫**：你哪个领域容易迷糊、有灵性或逃避
- **冥王星落宫**：你哪个领域执念最深、会经历彻底蜕变

**第4步：看相位 —— 能量之间的互动**

1. 先找**个人行星之间的相位**（日月、月金、金火等）：直接影响日常性格和内心冲突
2. 再找**外行星和个人行星的相位**：人生的大课题、大机遇
3. 重点关注：
   - 太阳的相位：自我意识的整合程度
   - 月亮的相位：情绪是否顺畅
   - 金星/火星的相位：感情模式是否顺利
   - 土星的相位：哪里有压力和功课
   - 木星的相位：哪里有贵人好运

**第5步：看宫位整体分布 —— 人生重心**

观察行星集中在哪些宫位：
- 集中在**1-6宫（下半部分）**：更关注自我、内在、个人生活
- 集中在**7-12宫（上半部分）**：更关注他人、社会、外部世界
- 集中在**左半部分（12-1-2-3-4-5-6宫）**：更主观、自我驱动
- 集中在**右半部分（6-7-8-9-10-11-12宫）**：更客观、受他人影响

> 空宫（没有行星的宫位）不代表那个领域空白，看宫头星座的守护星落在哪里即可。

**第6步：综合串联 —— 讲出一个完整的人生故事**

把以上所有信息整合起来，不是罗列，而是讲出一个有逻辑的故事：
- 这个人的核心性格是什么（太阳+月亮+上升）
- 他/她在事业上是什么样的（10宫+土星+火星）
- 在感情里是什么样的（金星+火星+7宫+5宫）
- 原生家庭带来了什么（4宫+月亮+土星）
- 人生最大的课题是什么（土星+冥王星+压力相位）
- 人生最大的幸运在哪里（木星+和谐相位）

### A.8 实战案例演示

**案例：太阳白羊 + 10宫 + 太阳刑土星**

套用公式拆解：

| 要素 | 含义 |
|------|------|
| 太阳 | 自我意志、人生追求 |
| 白羊 | 直接、冲劲、敢闯 |
| 10宫 | 事业、社会地位 |
| 刑土星 | 压力、阻碍、延迟 |

**完整翻译**：

> 你事业心很强，做事冲劲足、敢闯敢拼，渴望在事业上获得成就和认可。但事业路上经常碰壁、压力大，容易遇到权威打压或自我怀疑，成功来得比较晚，属于大器晚成的类型。早年事业挫折多，但每一次碰壁都在帮你积累实力，中年之后会越来越稳。

### A.9 常见误区提醒

1. ❌ **只看太阳星座**：太阳只是十颗星之一，完整星盘有十颗行星+宫位+相位
2. ❌ **凶相位=倒霉**：压力相位是成长课题，不是厄运；和谐相位也可能让人懒散
3. ❌ **空宫=那个领域没有**：空宫看宫头守护星，不代表空白
4. ❌ **星盘决定一切**：星盘是能量倾向和课题地图，不是判决书，选择和行动才是关键
5. ❌ **死记硬背释义**：理解底层逻辑（行星+星座+宫位+相位）比背条文重要
6. ❌ **只看单颗星**：星盘是整体，要结合相位、宫位、守护关系综合判断

### A.10 快速自查清单

拿到一张星盘，按这个清单逐项过一遍：

- [ ] 上升星座是什么？外在形象如何？
- [ ] 太阳落在什么星座、第几宫？核心自我是什么？
- [ ] 月亮落在什么星座、第几宫？情绪模式如何？
- [ ] 水星、金星、火星分别落在哪里？
- [ ] 木星落在哪里？好运和机遇在哪个领域？
- [ ] 土星落在哪里？压力和课题在哪个领域？
- [ ] 天海冥分别落在哪几宫？哪些领域有突变/迷幻/蜕变？
- [ ] 主要的和谐相位有哪些？天赋在哪里？
- [ ] 主要的压力相位有哪些？人生课题是什么？
- [ ] 行星集中在哪些宫位？人生重心在哪里？
- [ ] 四轴分别是什么星座？人生四大锚点如何？

> **最后一句话**：星盘是地图，不是剧本。它告诉你路的走向和地形，但怎么走、走多远，永远由你自己决定。
