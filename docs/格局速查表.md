# 格局速查表（占星相位格局与行星分布格局）

> 来源：传统与现代占星学"格局（Chart Patterns）"体系，经整理后收录，作为 AgentForge 星盘分析师的知识库速查文档（见《星盘分析功能设计》6.4 / 《星盘分析扩展规划》2）。
> 编辑说明：
> - 本表口径统一使用**回归黄道（Tropical Zodiac）** + 中文术语，与《星盘宫位完整解析》《星盘完整阅读逻辑手册》保持一致，不引入恒星黄道或替代说法。
> - 格局描述的是行星能量之间的结构性互动，**不代表宿命结论**。和谐格局也可能因过于安逸而荒废天赋，压力格局反而是成就感的来源。LLM 解读时须柔和表达、不做吉凶断言（见设计文档 6.2"不夸大、不恐吓"）。
> - 本文档不含格局的检测规则（容差设定、星体数量判定等），仅描述各格局的含义与解读思路，检测逻辑由排盘引擎在代码层实现。
> - 本文分两大板块：**一、相位格局**（由特定角度关系构成的几何图形）和**二、行星分布格局**（Marc Edmund Jones 七型，按整盘行星分布形态分类），每格局独立成节，便于 RAG 切片后精确命中单个格局的完整释义。

# 第一部分：相位格局

> 相位格局是由三颗及以上行星通过特定角度（合 0°、六合 60°、刑 90°、拱 120°、冲 180°、梅花 150°）构成的几何图形。格局越大、参与行星越多，对整盘的影响力越突出。

## 大三角（Grand Trine）

| 属性 | 说明 |
|------|------|
| **结构** | 三颗行星互相成 120° 拱相（三分相），构成一个等边三角形 |
| **元素** | 三颗行星须落在同一元素（火象/土象/风象/水象）的三个星座 |
| **性质** | 和谐、流畅、天赋型 |
| **含义** | 大三角代表一股天然的、毫不费力的才能流。涉及的元素决定了天赋的领域：火象主行动与热情、土象主务实与物质、风象主思维与社交、水象主情感与直觉。盘主在该元素领域"自带手感"，别人觉得难的事他/她觉得自然而然。 |
| **解读要点** | 1) 确认是哪种元素的大三角，天赋领域与该元素对应；2) 看三颗行星分别代表什么驱动力，天赋的具体表现形式；3) 看三个行星分别落在第几宫，天赋会在哪些人生领域显现；4) **警惕**：大三角过于顺遂可能导致安于现状、缺乏成长动力，天赋若不主动经营也可能荒废。 |
| **柔和提示** | 不要说"你天赋异禀、一生顺遂"，而说"你在某领域有天然的顺畅感，但天赋也需要主动经营才能发挥价值"。 |

## T三角（T-Square）

| 属性 | 说明 |
|------|------|
| **结构** | 两颗行星成 180° 对冲，同时都和第三颗行星（顶点星）成 90° 刑相，构成一个 T 字形 |
| **性质** | 压力、驱动、挑战型 |
| **含义** | T三角代表一种持续运转的内在张力。对冲的两颗行星产生来回拉扯的两股力量，而顶点星是这些张力的汇聚点和释放口——所有矛盾最终都在顶点星所代表的领域爆发或被处理。盘主往往在顶点星领域反复碰壁，但也正是在那里磨砺出真本事。 |
| **解读要点** | 1) 对冲的两颗行星代表什么冲突（如太阳冲月亮=自我与情感需求拉扯）；2) 顶点星是"泄压阀"，看它是什么行星、落在哪个星座和宫位——那里是矛盾的焦点，也是突破口；3) 顶点星的对宫位置是"空缺的脚"，代表盘主潜意识里渴望弥补的领域；4) T三角的能量虽然痛苦，但驱动力极强，许多成就卓越者都有 T三角。 |
| **柔和提示** | 不要说"你命苦、内在矛盾重重"，而说"你在某些领域会反复面临拉扯，但这些磨砺正是你成长最深的领域"。 |

## 大十字（Grand Cross / Grand Square）

| 属性 | 说明 |
|------|------|
| **结构** | 四颗行星构成一个正方形，两两之间成 90° 刑相，同时有两组 180° 对冲 |
| **元素** | 四颗行星落在同一品质（开创/固定/变动）的四个星座 |
| **性质** | 高压、多向拉扯、十字路口型 |
| **含义** | 大十字代表四股力量同时拉扯，盘主在多个方向上承受压力。能量被夹在十字路口中央，每个方向都在拉、每条路都不好走。但这恰恰是一种极强的历练：被迫学会平衡多方力量，在持续的矛盾中淬炼出超常的综合能力。 |
| **解读要点** | 1) 确认是哪种品质的大十字：开创型大十字主行动力与启动、固定型大十字主执着与坚守、变动型大十字主适应与流转；2) 看四颗行星分别代表什么、落在哪四个宫位，四条拉扯的线索分别指向哪些人生领域；3) 大十字的能量需要"找到重心"——不是消除矛盾，而是在矛盾中站住脚；4) 涉及角宫（1/4/7/10）的大十字对整盘影响极大，几乎贯穿一生。 |
| **柔和提示** | 不要说"你四面楚歌、处处受困"，而说"你同时在好几个领域面临课题，这些课题会把你磨练成一个综合能力很强的人"。 |

---

## 星群（Stellium）

| 属性 | 说明 |
|------|------|
| **结构** | 三颗及以上行星集中在同一个星座（和/或同一个宫位） |
| **判定** | 现代占星一般以 3 颗及以上行星（含日月，部分流派要求含个人行星）同落一个星座或宫位为准 |
| **性质** | 聚焦、集中、执念型 |
| **含义** | 星群代表盘主在某一个星座或宫位所对应的人生领域投入了极大的能量。那颗星座的风格或那个宫位的主题会成为盘主生命的核心焦点——既是最大的优势所在，也最容易因过度集中而失衡。星群就像一束聚光，亮处极亮、暗处极暗。 |
| **解读要点** | 1) 星群落在什么星座——该星座的特质被极度放大（如三星群落天蝎=执念、洞察、深层转化的特质被强化到极致）；2) 星群落在第几宫——该宫位的人生领域成为人生重心（如星群落 10 宫=事业几乎吞噬一切）；3) 星群中的行星之间有无相位互动，互动方式决定能量是协同还是内耗；4) 星群的对宫星座/宫位是被忽略的领域，需要提醒盘主关注平衡。 |
| **柔和提示** | 不要说"你执念太重、偏科严重"，而说"你在某个领域投入了超出常人的能量，这是你的核心竞争力，也要记得给其他领域留些关注"。 |

---

## 风筝（Kite）

| 属性 | 说明 |
|------|------|
| **结构** | 在大三角的基础上，第四颗行星与大三角中的一颗行星成 180° 对冲，同时与另两颗行星成 60° 六合 |
| **性质** | 和谐中有方向、天赋有出口型 |
| **含义** | 风筝格局是在大三角的"天赋流淌"基础上加了一个"对冲点"，这颗对冲星就像风筝的尾巴和线——给原本自满循环的天赋能量加了一个方向和出口。盘主不仅拥有大三角的天然才能，更有将才能导向外部世界的驱动力。 |
| **解读要点** | 1) 先按大三角思路解读天赋基础；2) 对冲星是"风筝的线"，看它是什么行星、落在哪——那里是天赋被引出、被外部检验的领域；3) 对冲星所在宫位往往代表盘主将天赋实际施展的人生舞台；4) 风筝比纯粹的大三角更有建设性，天赋不再是"闲置的顺手"，而是"被推动去用"的才能。 |
| **柔和提示** | 风筝格局整体偏积极，但仍需提醒盘主"天赋有了出口不代表不需要努力，对冲点本身也有拉扯感"。 |

---

## 神秘长方形（Mystic Rectangle）

| 属性 | 说明 |
|------|------|
| **结构** | 四颗行星构成两组对冲（180°），对冲之间互相以拱相（120°）和六合（60°）连接 |
| **性质** | 张力中有平衡、对中有通型 |
| **含义** | 神秘长方形格局中的两组对冲代表两对相反的力量，但拱相和六合为这些对立提供了疏通渠道。盘主虽然面对两对内在矛盾，但总能找到一种方式让对立的力量达成动态平衡。这种格局的人往往擅长在矛盾中找到务实的解决方案。 |
| **解读要点** | 1) 两组对冲分别代表什么两对矛盾；2) 拱相和六合连接的是哪几颗行星——那里是化解矛盾的"桥梁"；3) 看四颗行星落宫，矛盾和解决方案分别在哪些人生领域；4) 此格局的才能在于"调和"与"整合"，盘主在人生中反复练习将对立面统合。 |
| **柔和提示** | 不要把此格局说成"逢凶化吉"，而说"你面对矛盾时总能找到平衡点，这是一种很实用的整合能力"。 |

## 上帝之指（Yod / Finger of Fate）

| 属性 | 说明 |
|------|------|
| **结构** | 两颗行星成 60° 六合，同时都和第三颗行星（顶点星）成 150° 梅花相（Quincunx） |
| **性质** | 命运感、调整、使命型 |
| **含义** | Yod 在希伯来语中意为"手"，象征"命运之手指向某个方向"。顶点星代表的领域是盘主感受到一种说不清的、宿命般的使命或召唤。梅花相（150°）本身带有"不兼容需调整"的意味，两颗底部行星的能量以不顺畅的方式汇聚到顶点星，盘主需要反复磨合、调整才能将这股能量用对地方。 |
| **解读要点** | 1) 顶点星是"被指向的使命"，看它是什么行星、落在哪个星座和宫位——那里是盘主感受到命运召唤的领域；2) 两颗底部行星六合，代表一种潜在的支持力量，但这种支持需要被"翻译"成顶点星能接受的方式；3) Yod 常在 30 岁前后（行运土星对冲本命土星、行运天王星对冲本命天王星等时期）被"激活"，盘主在那段时期会有方向性的转折感；4) Yod 不是"命中注定要做什么"，而是"你会在某个领域反复感到一种说不清的牵引"。 |
| **柔和提示** | 不要说"你命中注定要做 X"，而说"你在某个方向上有一种强烈的内在牵引，这需要你在生活中反复磨合才能找到正确的表达方式"。 |

---

## 摇篮（Cradle）

| 属性 | 说明 |
|------|------|
| **结构** | 四颗行星构成两个六合（60°）、两个拱相（120°）和一组对冲（180°），形如摇篮 |
| **性质** | 潜能型、被动天赋、需激活 |
| **含义** | 摇篮格局整体偏和谐（六合+拱相），但一组对冲提供了张力。盘主拥有天然的才能储备（和谐相位），但如果不去主动激活这组对冲，才能可能一直沉睡在舒适区里。摇篮的关键在于"要不要摇动它"——主动面对对冲带来的课题，才能将潜能释放。 |
| **解读要点** | 1) 和谐相位（拱+六合）组成的才能基底是什么；2) 对冲的两颗行星代表什么课题，它们是摇篮的"启动开关"；3) 看四颗行星落宫，潜能和课题分别在哪些领域；4) 此格局最大的风险不是"不好"，而是"太舒服了不去动"。 |
| **柔和提示** | 不要把摇篮格局说成"躺赢"，而说"你有很好的天赋基础，但需要主动去面对某个课题，才能把潜在的天赋释放出来"。 |

---

## 大六分相 / 大卫之星（Grand Sextile）

| 属性 | 说明 |
|------|------|
| **结构** | 六颗行星互相成 60° 六合，构成一个正六边形（六芒星），须包含两组大三角 |
| **性质** | 极和谐、极罕见、综合天赋型 |
| **含义** | 大六分相是占星中最罕见、最和谐的格局之一，代表六颗行星之间的能量全部以六合（60°）顺畅连接。盘主拥有横跨多个元素和宫位的综合才能，事事皆有顺手的底子。但正因为过于和谐，也最容易出现"什么都不缺反而什么都不深入"的困境。 |
| **解读要点** | 1) 六颗行星分别代表什么、落在哪些星座宫位——才能覆盖的领域极广；2) 两组大三角各属什么元素——双重元素天赋的叠加；3) 此格局的核心课题是"聚焦"：什么都顺手时反而需要选择深耕方向；4) 极为罕见，出现时不要过度渲染"天选之人"。 |
| **柔和提示** | 不要将此格局神秘化或过度渲染，平和说明"你的才能覆盖面很广，关键在于找到最想深耕的方向"。 |

## 手指组合（Double Yod / Yod Kite）

| 属性 | 说明 |
|------|------|
| **结构** | 两个 Yod 共享一条底部六合边，或一个 Yod 的顶点星同时是另一个 Yod 的底部星 |
| **性质** | 双重使命、多向调整型 |
| **含义** | 双 Yod 代表盘主同时感受到两个方向的命运牵引，两股梅花相的"调整"能量叠加，人生方向感更复杂但也更具独特性。盘主可能长期处于"不知道自己到底该往哪走"的困惑中，但这恰恰意味着人生不是单线使命，而是多元路径。 |
| **解读要点** | 1) 两个 Yod 的顶点星分别指向什么领域；2) 共享的行星是什么角色，它是两个使命方向的交汇点；3) 双 Yod 的能量需要更长时间磨合，盘主的中年时期往往会有方向感逐渐清晰的过程；4) 不要急着给盘主"定方向"，而是帮助理解"多元路径本身也是一种使命"。 |
| **柔和提示** | 不要说"你命中要做两件事"或"你的人生方向很乱"，而说"你同时被几个方向牵引，这需要时间厘清，多元路径本身也是你独特的生命模式"。 |

# 第二部分：行星分布格局（Jones 七型）

> 由占星家 Marc Edmund Jones 提出，按整盘行星的分布形态分为七型。这一部分看的是"行星整体怎么铺"而不是"行星之间什么角度"。形态决定了盘主面对人生的基本态度和行为模式。

## 碗型（Bowl）

| 属性 | 说明 |
|------|------|
| **形态** | 所有行星集中在星盘的半圆内（不超过 180° 范围），另一半完全空缺 |
| **含义** | 碗型格局代表盘主是"半圆专家"——对集中在的那半圆领域极其熟悉，对空缺的那半圆领域充满好奇与向往。碗型人常有强烈的"想要拥有完整"的渴望，会主动去补足自己缺失的那一面。 |
| **解读要点** | 1) 行星集中在哪半圆（上半盘/下半盘/左半盘/右半盘）——集中的部分是"拥有"的领域，空缺的部分是"渴望"的领域；2) 碗的"边缘星"（Rim planet）是领头星，代表盘主主动出击的方向；3) 碗型人的人生往往从"半个世界"出发，逐步向空缺的那半边探索扩展。 |

---

## 瓮型 / 桶型（Bucket）

| 属性 | 说明 |
|------|------|
| **形态** | 行星集中在半圆内（类似碗型），但有一颗行星落在对面空缺的半圆中，形成"把手" |
| **含义** | 瓮型格局中那颗孤立的"把手星"是整盘最重要的导向星，所有集中在半圆里的能量都通过它来表达和释放。盘主的人生焦点高度集中在把手星所代表的领域，那颗星像一个漏斗，将所有能量倒向一个方向。 |
| **解读要点** | 1) 把手星是什么行星、落在哪个星座和宫位——这是盘主人生最突出的焦点和表达出口；2) 把手星的落宫往往代表盘主最在意的人生领域；3) 集中在半圆里的行星群是被"引导"的能量池；4) 把手星若有挑战相位，焦点领域的课题会更突出。 |

---

## 火车头型（Locomotive）

| 属性 | 说明 |
|------|------|
| **形态** | 行星分布在大约 240° 的范围内（占盘面的三分之二），剩余约 120° 空缺 |
| **含义** | 火车头格局代表盘主的人生有一种"轨道感"——行星分布像一列火车沿着固定方向推进。空缺的 120° 是"被拉着走"的方向，盘主会在那里感受到一种引力。火车头人的人生自带动力和方向感，不需要外界推动就能前进。 |
| **解读要点** | 1) 顺时针方向紧挨空缺区的第一颗行星是"火车头"（Leading planet），代表盘主前进的引擎；2) 空缺的 120° 区域在哪个宫位——那是盘主被"引力"拉着去面对的领域；3) 火车头人做事有节奏、有连贯性，但可能忽略空缺区的课题；4) 行进方向决定盘主是"向外推"还是"向内收"。 |

---

## 跷跷板型（See-Saw）

| 属性 | 说明 |
|------|------|
| **形态** | 行星分成两组，分布在星盘相对的两侧，中间有两个明显的空缺区 |
| **含义** | 跷跷板格局代表盘主的人生在两组力量之间来回摆荡。两组行星各代表一种关注重心，盘主在两极之间来回切换，需要在两端找到平衡。此型人善于看到事物的两面，但可能因反复摇摆而犹豫不决。 |
| **解读要点** | 1) 两组行星分别集中在哪些宫位——代表哪两个领域在跷跷板；2) 两个空缺区代表盘主容易忽略的"中间地带"；3) 跷跷板人最需要学会的不是"选一边"，而是在摆荡中找到动态平衡；4) 对冲相位多的盘更容易出现跷跷板特征。 |

## 撒型 / 散布型（Splash）

| 属性 | 说明 |
|------|------|
| **形态** | 行星均匀散布在整个星盘圆周上，无明显集中区，各象限行星数量相当 |
| **含义** | 撒型格局代表盘主的人生能量分散而均衡，兴趣广泛、不偏科。盘主对各个人生领域都有涉及，是"什么都懂一点"的通才型。但正因为分散，可能缺乏一处足够深的核心焦点。 |
| **解读要点** | 1) 行星均匀分布意味着盘主的人生没有明显的"盲区"；2) 重点看各象限的元素和品质是否平衡（数量匀但元素可能偏）；3) 撒型人的人生课题往往是"聚焦"——在广泛涉猎中找到值得深耕的方向；4) 此型最怕"什么都碰一下就走了"。 |

---

## 扇型 / 束型 / 扇骨型（Splay）

| 属性 | 说明 |
|------|------|
| **形态** | 行星以三组分散分布在三个不同的区域，形成三足鼎立的扇骨状结构 |
| **含义** | 扇型格局代表盘主在三个不同的人生领域各有一组集中的能量，形成三足鼎立。盘主的人生不是单线推进，而是三条腿走路。此型人有独立精神、不随大流，三条线之间的张力是人生的活力来源。 |
| **解读要点** | 1) 三组行星分别集中在哪三个区域——代表三条人生主线；2) 三条线之间有无相位连接——有则三足互通，无则各行其是；3) 扇型人讨厌被框死在单一身份里，人生需要多元出口；4) 三个区域落在什么象限和宫位群，决定盘主的多元重心。 |

---

## 束型 / 捆型（Bundle）

| 属性 | 说明 |
|------|------|
| **形态** | 所有行星集中在星盘约 120° 的狭窄弧段内（约占盘面三分之一），形如一束 |
| **含义** | 束型格局代表盘主的人生能量高度集中在某个狭窄区域，是"专家中的专家"。盘主在某个特定领域投入几乎全部能量，有极强的专一性和深度，但也容易视野局限。此型人的人生道路窄而深，常在某一专业领域做到极致。 |
| **解读要点** | 1) 集中的 120° 落在哪些星座和宫位——那是盘主"几乎全部人生"的领域；2) 束型人的人生满足感来自深耕而非广撒；3) 看束中行星之间的相位，集中区域内的相位互动极为密集；4) 此型最需要提醒的是"在深耕之余保留一些对外部世界的开放度"。 |
