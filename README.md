# AgentForge
AgentForge 是一个面向开发者与企业的开源 AI Agent 构建平台。它帮助用户快速创建具备知识库（RAG）、工具调用（Tool Calling）、记忆与工作流执行能力的智能体，可用于搭建 AI 编程助手、AI 知识库助手、AI 客服助手、AI 研究助手和 AI 数据分析助手等场景。 平台采用 Vue3 + Spring Boot + Python AI Service 的三层架构：前端负责交互与配置，Spring Boot 承担用户、智能体、对话、文件等业务与认证体系，Python AI Service 专职大模型推理、Agent 编排、RAG 检索与工具执行，职责边界清晰、可独立演进。
